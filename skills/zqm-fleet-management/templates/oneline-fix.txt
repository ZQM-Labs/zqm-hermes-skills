# oneline-fix.txt — HTTP-fetch-first bootstrap wrapper (round-2 corrected pitfall #16)
# Fetches zqm-bootstrap.ps1 over HTTP from the Garden WEB SERVER, then runs the local copy.
# Defeats BOTH node-console UNC backslash-doubling AND the no-SMB-cred "user name or password
# is incorrect" wall (Node-2/3 had no cached SMB cred to Garden-01; Node-4 did, so only 2/3 failed).
# No backslashes in the curl step; the web/ share is served at the web ROOT.
#
# CRITICAL: use hostname ZQM-Garden-01 (resolves to 192.168.1.173). Do NOT use IP 192.168.1.40
# — that is a DIFFERENT box (Garden-02, agent-only SMB) and returns the wrong content.
#
# Paste EXACTLY (forward slashes, hostname, no backslashes in the curl step):
cmd /c "mkdir C:\zqm 2>nul & curl -s -o C:\zqm\bootstrap.ps1 http://ZQM-Garden-01/zqm-bootstrap.ps1 & powershell -NoProfile -ExecutionPolicy Bypass -File C:\zqm\bootstrap.ps1"
