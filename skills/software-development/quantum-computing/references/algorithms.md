# Algorithms

## GHZ
- Entanglement entropy: 1.0 for maximally mixed bipartition.
- Concurrence near 0? GHZ is not a Bell pair.

## QFT
- Uniform-like distribution on 4+ qubits.
- Phase kickback recorded in gate history.

## Grover
- Amplitude concentrated on marked state.
- Iterations: pi/4 * sqrt(N).

## Bell
- Two-qubit entangled state.
- Entropy ~ 0 due to pure global state and single-element subsystem.

## Teleport
- Classical corrections emitted in payload.
- Message qubit prepared as |+> for traceability.

## Deutsch-Jozsa
- Constant/binary determination from leading amplitudes.
- Deterministic unless noise added.
