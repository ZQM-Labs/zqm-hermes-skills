# Commercial use

## What this repo is

This repo is the open checkout surface for ZQM Attestation Toolkit. The repo itself is MIT/Apache-2.0/BSD-3 licensed. Commercial fulfillment is separate.

## How to buy

1. Open a GitHub issue with the `purchase` label.
2. State SKU(s) from `SKU_CATALOG.md`.
3. Automated fulfillment bot delivers the artifact.

## What you get

- CMS-signed attestation report (if SKU includes CMS-SIGNED-DELIVERABLE).
- Provable TPM/BitLocker/hash evidence.
- Ownership of methodology.
- No dependency on Velociraptor/Wazuh for delivery.
